# Course-note files

Place student-facing weekly notes in this directory. Notes may be maintained as
editable Markdown files or distributed as PDFs. For Markdown notes, point the
homepage link to the file's GitHub `blob` URL so students see GitHub's rendered
view. For PDFs, use names such as `week01.pdf` through `week14.pdf`, with
`week08_midterm_review.pdf` for the midterm meeting.

After adding a file, change its matching `data-released` value in
`public/index.html` from `false` to `true`.
