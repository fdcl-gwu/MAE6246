MAE 6246 - Week 11 MuJoCo example

Design state-feedback and observer gains for a beam with a sliding mass,
then compare the linear model with nonlinear MuJoCo simulation.

In Colab: run the notebook cells in order. The setup cell installs missing
dependencies and downloads mjsim.py automatically when needed.

Locally: extract the bundle, open week11_mujoco_controller_observer.ipynb
in Jupyter, and run all cells. Keep mjsim.py beside the notebook.
The setup cell installs missing dependencies into the notebook's Python
environment. An internet connection is needed for the initial installation.
